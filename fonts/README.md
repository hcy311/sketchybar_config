Bundled fonts in this folder:

- `HackNerdFont-Regular.ttf`
- `sketchybar-app-font.ttf`

Install them with:

```sh
cp fonts/*.ttf ~/Library/Fonts/
```

Notes:

- `SF Pro` and `SF Mono` are referenced by the config but are not bundled here.
- They are Apple fonts and should not be redistributed from this repository.
- On macOS they are usually already available as system fonts.
