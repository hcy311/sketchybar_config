# SketchyBar Config

Personal SketchyBar configuration using the Lua API.

## Notes

- `SketchyBar.app` is generated locally to make macOS Accessibility permissions reliable for the Homebrew SketchyBar binary.
- After installing or upgrading SketchyBar, run:

```sh
./scripts/sync_sketchybar_app.sh
```

- Helper binaries are generated by the config startup through `helpers/makefile`.
- The wallpaper color helper is compiled from `scripts/wallpaper_color.swift` when needed.
